# 2人用支出清算アプリ（モック）

## 🎯 目的
- 2人だけで使う立替・清算管理アプリのモック
- **台帳方式**：すべての支出や清算を「仕訳」として記録し、残高や差額を計算
- 今はブラウザだけで動く（配列保存）。将来は API + DB に置換可能
- 学習用としてシンプルな設計を採用

## 📂 ディレクトリ構成
```
project-root/
index.html            # 画面本体
style.css             # 見た目
app/                  # アプリの起動・状態管理
main.js                 # 初期化・イベント配線
router.js               # 画面切替（SPAっぽくセクション切替）
state.js                # 現在ユーザなどUI用の状態
ui/                   # 画面描画（-View）
expensesView.js         # 支出一覧の表示
settlementView.js       # 清算通知・履歴の表示
logic/                # アプリのルール（-Service）
ledgerService.js        # 台帳処理（集計・仕訳生成・逆仕訳）
expensesService.js      # 支出処理（追加・編集・削除）
settlementsService.js   # 清算処理（差額計算・申請・承認/却下）
db/                   # 保存処理（-Repository）
expensesRepository.js    # 支出の保存/取得
ledgerRepository.js      # 台帳仕訳の保存/取得
settlementsRepository.js # 清算の保存/取得
```


## 🔄 処理の流れ
1. **ui (-View)**  
   - DOMを操作して画面を表示  
   - ボタン押下やフォーム送信で `logic` を呼び出す  

2. **logic (-Service)**  
   - アプリのルールを実装  
     - 支出 → 等分仕訳を作る  
     - 編集/削除 → 逆仕訳を積む  
     - 清算 → 差額計算・承認なら相殺仕訳  
   - `db` を呼び出して保存/取得する  

3. **db (-Repository)**  
   - データ保存の仕組みを隠蔽  
   - 今は配列に保存 → 将来は API + DB に差し替え可能  

4. **app**  
   - 全体の起動・イベント配線  
   - UIの再描画をまとめて呼ぶ  


## 🧮 台帳方式ルール
- **支出**：2000円立替 → A:+1000, B:-1000  
- **編集**：元仕訳を逆仕訳（符号反転）で相殺 → 新しい仕訳を追加  
- **削除**：逆仕訳を追加 + 論理削除フラグ  
- **清算承認**：差額を相殺する仕訳を追加（B → A に 1250円 → A:-1250, B:+1250）

## ➕清算計算ルール
- 支出は2人で等分
- 金額が奇数の場合、**端数は支払者に寄せる**ルール
  例: 1円の支出 → 支払者 +1, 相手 0

## 🔒 ロックのルール
- **清算申請中**は、UIで支出の編集・削除を禁止  
- 承認または却下後に再び編集可能  


## 🚀 実行方法
1. サーバを起動（ESM対応のため必須）  

```
cd project-root
python3 -m http.server 8000
```
2. ブラウザで [http://localhost:8000](http://localhost:8000) を開く
