# 命名用語リスト（カテゴリ別）

## 🖥 UI系（画面・見た目）
| 英語    | 日本語     | 備考 |
|---------|-----------|------|
| view    | 表示       | UIファイルの接尾辞。例：`expenses-view.js` |
| ui      | 画面       | 画面描画層のディレクトリ名 |
| button  | ボタン     | UI部品。例：`c-button--primary` |
| input   | 入力       | フォーム要素。例：`c-input--date` |
| row     | 行         | テーブル行。例：`c-expense-table__row` |
| cell    | セル / 列  | テーブルのセル。例：`c-expense-table__cell` |
| actions | 操作       | ボタン群をまとめる領域。例：`__actions` |
| notice  | 通知       | 清算通知などのメッセージ表示ブロック |
| panel   | パネル / 区画 | 画面をまとめる箱。例：清算履歴の区画 |

---

## 💰 データ系（業務ドメイン）
| 英語       | 日本語   | 備考 |
|------------|---------|------|
| expense    | 支出     | 支出処理・画面など |
| settlement | 清算     | 清算処理や清算画面 |
| ledger     | 台帳     | 集計・仕訳生成・逆仕訳 |
| amount     | 金額     | 入力や計算に使う数値 |
| date       | 日付     | 支出日や最終更新日 |
| payer      | 支払者   | 誰が支払ったか |
| category   | カテゴリ | 食費/交通/日用品など |
| memo       | メモ     | 任意の補足テキスト |
| summary    | サマリー / 集計 | 差額表示や要約 |
| history    | 履歴     | 清算履歴や過去ログ |

---

## 🔄 状態系（UIや処理の状態）
| 英語    | 日本語       | 備考 |
|---------|-------------|------|
| active  | アクティブ / 表示中 | SPAで現在表示中の画面。例：`is-active` |
| loading | ローディング       | 読み込み中。例：`is-loading` |
| invalid | 無効 / 入力エラー   | バリデーションNG。例：`is-invalid` |
| empty   | 空データ           | リストやテーブルが空。例：`is-empty` |
| save    | 保存               | 保存処理やボタン。例：`js-save` |
| edit    | 編集               | 編集処理やボタン |
| delete  | 削除               | 削除処理やボタン |
| settle  | 清算申請           | 清算実行処理やボタン。例：`js-settle` |
| login   | ログイン           | ログイン画面や処理 |
| user    | ユーザ             | 現在のログインユーザ |

---

## 🏗 アプリ構造系（ディレクトリ・層）
| 英語       | 日本語       | 備考 |
|------------|-------------|------|
| app / core | アプリ / 中核 | 起動・ルータ・状態管理。運用では `core` が明確 |
| state      | 状態         | UI用の状態。例：`app-state.js` |
| service    | サービス / 処理 | ビジネスロジック層。例：`expenses-service.js` |
| repository | リポジトリ / 保存 | 永続化層。例：API通信やDB処理 |
| utils      | ユーティリティ | 共通関数（フォーマット・バリデーション等） |
